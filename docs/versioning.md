# Versioning And Branching

## Branches

- `main`: 稳定可演示版本，只放确认后的阶段成果。
- `codex/*`: 设计和功能迭代分支，后续调整优先从该前缀开新分支。

## Versions

- `0.1.x`: 毕设 App 的低保真到中保真交互原型阶段。
- `0.2.x`: 补充真实页面状态、表单校验、数据结构和更多 Figma 对齐。
- `1.0.0`: 答辩或最终展示可用版本。

## Commit Style

提交信息使用简短英文动词短语，例如：

```text
Initial Vite mobile prototype
Refine garden care interactions
Align visit flow with storyboard
```
